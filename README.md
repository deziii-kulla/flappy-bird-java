# Flappy Bird - JavaFX

A Flappy Bird-style desktop game developed using Java and JavaFX.

This project was created to practice Java programming, object-oriented concepts, GUI development, event handling, animation, and basic game logic.

## Features

* Start menu
* Flappy Bird movement using the spacebar
* Randomly generated pipes
* Collision detection
* Live score tracking
* Best-score tracking
* Pause and resume functionality
* Game-over screen
* Retry option
* Exit option
* Graphical game interface using JavaFX

## Technologies Used

* Java
* JavaFX
* Apache NetBeans
* Object-Oriented Programming (OOP)

## How to Play

1. Start the application.
2. Click Start.
3. Press the Spacebar to make the bird fly upward.
4. Avoid hitting the pipes.
5. Try to achieve the highest score possible.
6. Use the Pause button to pause or resume the game.
7. After losing, select Retry to play again or Exit to close the game.
